# Mini Task Manager

A simple task management application built with React and Supabase.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed or uncompleted
- Delete tasks
- Tasks are stored in Supabase
- Responsive and simple user interface

## Technologies Used

- React
- Vite
- Supabase
- JavaScript
- CSS

## Database

The application uses a Supabase PostgreSQL database with a `tasks` table containing:

- `id`
- `title`
- `completed`
- `created_at`
